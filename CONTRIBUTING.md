# Guia de Contribuição

## Convenções de Commit
Seguimos o padrão Conventional Commits:

- `feat:` Nova funcionalidade
- `fix:` Correção de bug
- `docs:` Documentação
- `style:` Formatação
- `refactor:` Refatoração de código
- `test:` Testes
- `chore:` Manutenção

Exemplo: `feat: adicionar endpoint de criação de tarefas`

## Fluxo de Trabalho
1. Crie uma branch a partir de `develop`
2. Nomeie como `feature/nome-da-funcionalidade`
3. Faça commits atômicos e descritivos
4. Abra PR para `develop`
5. Aguarde review e aprovação
